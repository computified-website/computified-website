Servers

Server Installation & Maintenance

Servers set up correctly from day one, then kept backed up, patched, monitored and running with ongoing maintenance.

Reliable servers, properly looked after

Servers hold the files, accounts, camera recordings and applications your organization depends on. Computified installs and configures physical and virtual servers, including file servers, NAS storage, NVR (video recording) servers and domain servers, and sets them up with sensible security and backups.

After installation, a server needs regular care. Our ongoing maintenance plans cover backups, updates and patching, monitoring and hardware upkeep, so problems are caught early instead of after something fails.

What’s included

  • Server planning, setup and installation (physical and virtual)
  • File servers and NAS (network storage) setup
  • NVR servers for security camera recording
  • Domain servers: user accounts, groups and permissions
  • Configuration of storage, shares, users and network access
  • Backup setup and restore testing
  • Operating system and software updates and patching
  • Monitoring of server health, storage and backups
  • Hardware upgrades and repair: drives, memory and components
  • Ongoing maintenance plans
